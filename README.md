# Pokemon Yellow Help Magazine images

Static, versioned image assets for a VRChat help-magazine reader.

Release: `guides/pokemon-yellow/v1/manifest.json`

- 125 source PDF pages; front cover 1, back cover 125.
- Interior pages 2-124 in 31 four-page atlases, 62 reading spreads.
- 2048 x 2048 opaque RGB PNG; final unmatched side is white.
- Original scans are fitted without cropping, with physical-page aspect compensation.
- Cover layout is documented numerically in the manifest.

The publishing account owner supplied the PDF and authorized publication of these rendered pages.

material and is not an official or endorsed Nintendo publication.

No original PDF, Unity project, purchased magazine geometry, scripts, materials, or animation
assets are included. The Unity integration is maintained privately and independently.

Versioned URLs must remain immutable; publish future image changes under a new version folder.
